# Шаблон вопроса

Скопируйте `question-template.json`, заполните поля и добавьте объект в `../frontend.json`.
Id — `fe-<тема>-NNN` (следующий свободный номер темы). Ответ пишите так, как его стоит произнести вслух;
`mustMention` — чек-лист для интервьюера. Пока ответ не вычитан человеком, оставляйте `"reviewedAt": null`.
Запустите `npm run validate-questions`.
